# Sistema Acadêmico em C

Projeto desenvolvido para prática de lógica de programação em C.

## Funcionalidades

- Média aritmética
- Média ponderada
- Cálculo de exame final
- Conceitos A, B, C, D e E
- Validação de entradas
- Menu interativo

## Conceitos utilizados

- Variáveis
- Estruturas condicionais
- Laços de repetição
- Switch case
- Operadores lógicos
